## Changes applied

- Place the five selected projects above the technology section.
- Give each project a bilingual public overview with purpose, workflows and stack.
- Keep the four private source repositories private; overview pages contain no private implementation files or application data.
- Describe backend and database technologies already used in the featured projects.
- Add navigation within the README and a project-specific contact invitation.
- Keep the existing avatar, public portfolio source and original visual theme.

No employment history, client results, certifications, years of experience, or usage metrics have been invented. Blog, video, sponsorship and award sections require real corresponding material and are not included.

Artwork and text are original. The reference profiles' artwork and biography text are not copied. Toolkit icon attribution is in [the assets documentation](../assets/README.md).
